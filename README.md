## How I work

- Map how the work actually moves before automating any of it. Often the biggest win is fixing a handoff before any AI gets added.
- AI handles the reading and talking. Code handles anything that has to be exact, like bookings, prices and totals.
- Heavy use of AI coding tools, with specs, tests and review so the output is something I can stand behind.
